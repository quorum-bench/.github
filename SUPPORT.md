# Onde pedir ajuda

Documento interno QUORUM · 15/11/2026 · Estação: Construir · Artefato: guia de suporte da organização

| Você quer | Onde |
| --- | --- |
| Entender um repositório | O `README.md` e o `docs/INDEX.md` dele, com o guia de começar e o de solução de problemas |
| Entender uma decisão | Os ADRs no repositório [docs](https://github.com/quorum-bench/docs) |
| Avisar de um defeito | Uma issue com o modelo "Defeito" no repositório do defeito, sem print com nome, e-mail ou empresa |
| Propor uma mudança | Uma issue com o modelo "Fatia", e depois o PR, como diz o [CONTRIBUTING.md](CONTRIBUTING.md) |
| Avisar de uma falha de segurança | Nunca por issue: siga o [SECURITY.md](SECURITY.md) |

Os repositórios são privados durante o pré-lançamento: as issues e os PRs ficam para quem é membro da organização.
